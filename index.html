أنشئ تطبيقًا قرآنيًا باللغة العربية باسم "وِرْد" في ملف واحد index.html (HTML + CSS + JavaScript خام، بدون إطار عمل أو أدوات بناء)، بنفس بنية وتصميم الملف المرفق، مع إضافة الميزات والإصلاحات أدناه. ## الصيغة المطلوبة - ملف واحد، dir="rtl" و lang="ar"، يعمل بفتحه مباشرة وعلى GitHub Pages. - الخطوط: Amiri للعناوين وTajawal للنص. الأيقونات: Font Awesome عبر CDN. - الألوان: --primary:#1b4332 ، --secondary:#2d6a4f ، --accent:#d4af37 ، خلفية #f8f9fa. - الهيكل: ترويسة ثابتة بتدرج أخضر، قسم الفهرس (بحث + شبكة بطاقات السور)، قسم القراءة (مشغل صوتي ثابت + آيات)، نافذة منبثقة للتفسير، تذييل. - تصميم جوال أولًا، متجاوب، بحاوية بعرض أقصى 800px. ## المصادر (لا تكتب نص القرآن يدويًا) - فهرس السور: api.alquran.cloud/v1/surah (مصدر رئيسي) مع بديل احتياطي، ووحّد حقول المصدرين في دالة واحدة (name, numberOfAyahs, revelationType). - نص الآيات بالرسم العثماني: quran-uthmani من alquran.cloud، وخيار عرض صور الآيات من cdn.islamic.network كبديل. - التفسير: ar.muyassar من alquran.cloud. - الصوت: روابط mp3quran.net لسور كاملة، مع قارئين على الأقل (العفاسي، عبدالباسط، المنشاوي)، واستخدم قائمة القرّاء من api.mp3quran.net بدل كتابة الروابط يدويًا. ## الميزات 1. بحث عن سورة (مع تجاهل التشكيل والهمزات) وفلترة مكية/مدنية. 2. قراءة السورة آية بآية مع زر تفسير يفتح النافذة المنبثقة. 3. مشغل صوتي: اختيار القارئ، تكرار السورة، سرعة التشغيل، ومتابعة تلقائية للسورة التالية. 4. حفظ آخر موضع قراءة، والمفضلة، والوضع الليلي، وحجم الخط في localStorage. 5. PWA: manifest وservice worker في ملف منفصل sw.js لتخزين الواجهة مؤقتًا. 6. زر "تحميل APK" الحقيقي: اجعله زر "تثبيت التطبيق" (beforeinstallprompt) بدل alert وهمي. ## إصلاحات مطلوبة (أخطاء في الملف المرفق) - بطاقة السورة تقارن revelationType بـ 'Meccan' بينما المصدر الأول يحوّلها لـ 'مكية'، فتظهر كل السور "مدنية". وحّد القيم. - تمرير نص التفسير داخل onclick يكسر الصفحة مع علامات الاقتباس. استخدم addEventListener وdata-attributes. - عالج فشل تحميل الصور والصوت برسائل واضحة وزر إعادة المحاولة. - أضف تحميلًا كسولًا وتجزئة عرض الآيات في السور الطويلة (مثل البقرة). - أكمل الملف بالكامل (النسخة المرفقة مقطوعة عند دالة showTafsir) وأغلق وسوم script وbody وhtml. ## الجودة - ARIA وتنقل بلوحة المفاتيح وتباين ألوان جيد. - كود منظم بدوال صغيرة وتعليقات عربية مختصرة. - README بالعربية يشرح التشغيل والنشر والمصادر والتراخيص. ابدأ بإنشاء index.html كاملًا يعمل، ثم أضف sw.js وREADME.md.
